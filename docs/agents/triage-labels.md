# Triage Labels

The skills speak in terms of five canonical triage roles. This file maps those roles to the status strings used in local issue files.

| Canonical role    | Local `Status:` value | Meaning                                  |
| ----------------- | --------------------- | ---------------------------------------- |
| `needs-triage`    | `needs-triage`        | Maintainer needs to evaluate this issue  |
| `needs-info`      | `needs-info`          | Waiting on reporter for more information |
| `ready-for-agent` | `ready-for-agent`     | Fully specified, ready for an AFK agent  |
| `ready-for-human` | `ready-for-human`     | Requires human implementation            |
| `wontfix`         | `wontfix`             | Will not be actioned                     |

When a skill mentions a triage role, use the corresponding local `Status:` value from this table. Edit the right-hand column if the vocabulary changes.
